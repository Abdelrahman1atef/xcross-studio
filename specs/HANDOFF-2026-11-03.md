## Root causes found on the device (app A, evidence from the built app)

| Symptom | Cause |
|---|---|
| Map screen crashes | The generic Runner (`runner_shim.dart:280-327`) never runs `AppDelegate.swift`, so `GMSServices.provideAPIKey` is never called. The SDK is linked: `_OBJC_CLASS_$_GMSServices` is exported. |
| No push, FCM token null | The profile has no `aps-environment`: there is no entitlements file and xcross infers nothing (`flutter_bundle_assembler.dart:398-423`). The App ID is `XCR-…` (`pubspec.yaml` `xcross: bundle_id: prefixed`), while APNs and Firebase are bound to the real ID. |
| Firebase "not initialized" | `FIRApp` is linked and initialized from Dart. Bundle-bound services (Installations, FCM, bundle-restricted API keys) fail on the `XCR-` ID. **Confirm with a log capture.** |
| Silent prefixed App ID | Builds from the GUI never get the first-build question (`bundle_identity_resolver.dart:88-92, 129-133`). |
| Capability errors | A 403/404 stops the build (`appstoreconnect.dart:276`); a 409 is logged as "Enabled" (`developer_services_client.dart:233`). |
